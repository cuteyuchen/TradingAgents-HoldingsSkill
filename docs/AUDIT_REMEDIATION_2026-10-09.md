## 权限与兼容性

实例管理员复用既有 `can_manage_market_settings()` 规则，即数据库中首个注册账户；没有引入角色表、配置密钥或迁移。普通账户仍可读取历史覆盖、市场事实与自己的治理提案，但操作全局生产状态会得到 `403 system_operator_required`。现有单人部署的首个账户仍可完成治理和运维操作。前端现有 API 错误处理显示 403；普通用户运维页面可能显示权限错误，按权限收敛菜单/按钮可在后续 UI 批次完成。

账户版本前缀变化会使旧分析/日计划不能继续以旧账户版本通过执行门；需重新分析以获得新版本，而不是绕过过期检查。修改证券代码会重新要求身份审核；已人工确认的身份在仅改金额时保持有效。创建/修订时间仍规范化为 UTC，交易日期按上海时区。旧数据疑似金额矛盾、百分数单位错误或截图时刻不明时，必须先做只读诊断和人工核对；此批不自动修库。
