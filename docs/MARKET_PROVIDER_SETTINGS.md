# 同花顺金融数据配置与导航

在「设置 → 数据与行情 → 同花顺金融数据」输入 API Key 并保存，随后可点击「探测能力」检查连接及接口权限。

- 行情密钥供整个部署实例共享，只有首个注册账户可保存、替换或移除；其他账户可查看状态。
- 系统设置使用现有 `APP_SECRET_KEY` 加密，写入 `market_provider_settings` 表，优先于 `FUYAO_API_KEY` 环境变量。密钥不会通过配置读取接口或状态接口回传，也不写入浏览器存储。
- 「恢复环境配置」移除系统保存的密钥，重新读取部署环境中的 `FUYAO_API_KEY`；环境未配置时，Fuyao 标记为未配置，行情仍按原有备用数据源策略处理。
- 配置对后续创建的行情、历史数据和分析客户端生效，无需重启。已有行情缓存和正在进行的请求仍遵循原有生命周期。
- 保存成功仅代表配置成功；供应商权限与连接以探测结果为准。真实验证就绪检查仍要求成功的真实数据和分析记录。

发布前执行正常的 `alembic upgrade head`，应用迁移 `20261008_0024`。维护稳定的 `APP_SECRET_KEY`，数据库备份会保留加密配置。

所有登录后的业务页面统一使用常驻左侧主导航；小屏幕由左上角菜单打开左侧抽屉。运维页面以中文展示状态、检查项与原因，原始接口状态码保持不变，诊断代码可通过说明的悬停提示查看。
